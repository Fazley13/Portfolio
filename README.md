# Fazley Rabbi — Portfolio

A responsive Next.js portfolio for AI/ML research and software engineering work.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Deploy

Import this folder into Vercel. The project uses Next.js and requires no environment variables for the current client-side demo features.

## Notes
- Technology logos use the Devicon stylesheet from jsDelivr, so an internet connection is needed to load those icons.
- Research section contains summaries and animated topic visuals only. Research PDF files and paper-download links have intentionally been excluded.
- Contact form prepares an email in the visitor's default email application; it does not submit to a backend.
- The portfolio assistant is a local FAQ demo, not a live LLM integration.
